# damai-learning 学习笔记

> 这份笔记随项目演进持续更新。代码由学习者按照步骤执行，笔记由 Codex 负责整理和维护。

## 学习目标

通过一个简化版票务项目，形成阅读和理解 Java 后端工程的能力：

- 看懂 Spring Boot 项目的目录和启动过程
- 能够沿着 Controller、Service、Mapper 追踪业务调用链
- 理解常见工程化基础设施为什么存在
- 理解 MySQL、Redis、消息队列和 Elasticsearch 在真实业务中的作用
- 最终能够阅读普通版大麦的核心代码，并逐步理解大麦 Pro 的高级设计

## 学习方式

每个知识点按照固定顺序学习：

```text
提出问题
→ 理解原始实现的缺陷
→ 获得本次需要添加的代码
→ 学习者亲自修改和运行
→ 观察运行结果
→ 解释完整调用流程
→ 对照大麦项目
→ 提交 Git 记录
```

没有经过学习者亲自运行验证的内容，不记录为“已完成”。

## 项目演进记录

### V0：最小可运行的 Spring Boot 项目

#### 当前代码包含

- Java 17
- Maven
- Spring Boot 3.5.16
- Spring Web
- 应用启动类
- 一个 GET 测试接口
- 基础自动化测试

#### Maven项目坐标

```xml
<groupId>com.damai.learning</groupId>
<artifactId>damai-learning</artifactId>
<version>0.0.1-SNAPSHOT</version>
```

- `groupId`：项目或组织的标识
- `artifactId`：当前项目名称
- `version`：项目版本，`SNAPSHOT`表示开发中的版本

#### 核心依赖

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

`spring-boot-starter-web`主要提供：

- Spring MVC
- JSON序列化
- 内置Tomcat
- Web应用常用依赖

#### 启动入口

```java
@SpringBootApplication
public class DamaiLearningApplication {

    public static void main(String[] args) {
        SpringApplication.run(DamaiLearningApplication.class, args);
    }
}
```

`@SpringBootApplication`启用自动配置和组件扫描。启动类放在`com.damai.learning`包下，因此能够扫描其子包中的Controller等组件。

#### 第一个接口

```java
@RestController
@RequestMapping("/api")
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "damai-learning is running";
    }
}
```

最终接口地址：

```text
GET /api/hello
```

调用流程：

```text
HTTP请求
→ 内置Tomcat
→ Spring MVC
→ HelloController.hello()
→ HTTP响应
```

#### 本阶段验证命令

运行测试：

```powershell
mvn test
```

启动应用：

```powershell
mvn spring-boot:run
```

在另一个PowerShell终端调用接口：

```powershell
Invoke-RestMethod -Uri 'http://localhost:8080/api/hello'
```

预期响应：

```text
damai-learning is running
```

#### 与大麦项目的关系

大麦项目中的每个微服务最终也是一个独立的Spring Boot应用。学习版目前把所有业务放在一个应用中，等单体业务理解后再讨论服务拆分。

#### 本阶段需要理解

- Maven通过`pom.xml`管理什么
- `main`方法如何启动Spring Boot
- 为什么启动类通常放在根包
- Controller如何映射HTTP请求
- `/api`和`/hello`如何组合成完整地址
